## Sobre o projeto
Projeto educacional de geografia, com foco no aprimoramento de CSS e HTML.

## O que o projeto contempla
O projeto possui conteúdo informativo sobre os pontos extremos do Brasil.  
No código, foram utilizados:

- JavaScript educacional
- Estrutura de HTML  
- Estrutura de CSS  

## Como utilizar
O projeto roda diretamente no navegador.  
Acesse o site:

https://emhinha.github.io/OsExtremosDoBrasil/

## O que foi aprendido
Neste projeto, aprendi a melhorar a estética das minhas páginas e a estruturar melhor o HTML, aprimorando principalmente meus aspectos menos lógicos (parte visual e organização).
